# API tests for Yandex Samokat

Автотесты для учебного сервиса «Яндекс.Самокат».
Его документация: qa-scooter.praktikum-services.ru/docs/

## Технологии

- Python
- Selenium
- PyTest
- Allure

## Структура проекта

```
/
├─ allure-results/
├─ tests/
├─ conftest.py
├─ ...
```
## Установка
```
pip install -r requirements.txt
```

## Запуск тестов
```
pytest tests/ -v
```
